# Spot the Scam
A classroom website about email phishing, smishing (texts), vishing (calls), and quishing (QR codes).

## GitHub Pages
Upload this ZIP's contents to your repository. Keep index.html at the root.
Enable GitHub Pages from your main branch and root directory. No build or server is needed.

## Present to your class
1. Overview: introduce the four types and explain the common role of trust and pressure.
2. Spot the Signs: work through the four illustrated scenarios, warning signs, safe responses, and discussion prompts.
   Use Present one topic to show one section at a time. Use Next, Previous, or the topic links.
3. Class Quiz: classmates click Join Kahoot and enter the PIN you display.
   Host your live game separately from your Kahoot account.
Optional: solo.html offers eight practice scenarios with four choices and answer explanations.

kahoot-questions.txt contains an updated eight-question set for manually adding to Kahoot.
Changes here do not change an existing quiz in your Kahoot account.

## Files
index.html: overview
learn.html and lesson.js: lesson and presentation controls
practice.html: Kahoot join link
solo.html and app.js: standalone practice
style.css: light techno styling
examples/: fictional email images

The text, call, and parking examples are built into the lesson HTML.
Example addresses are fictional; the parking-code illustration is not scannable.
FTC and FBI sources are linked on the lesson page.
